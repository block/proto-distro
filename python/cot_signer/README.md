# Chain of Trust (CoT) Signer

A Python tool to help with re-signing certificates generated by the `cert_create` tool for the Chain of Trust for STM32MP1 series images. This tool is designed to fix up hashes, public keys, and signatures in the certificate chain.

## Features

- Sign root, intermediate, and leaf level certificates
- Print and verify certificate contents
- Verify the entire Chain of Trust
- **Warning** Only supports ECDSA prime256v1 with SHA256
- **Warning** Only tested with STM32MP131f platform

## Related Documentation

- [STM32 TF-A BL2 Trusted Board Boot](https://wiki.st.com/stm32mpu/wiki/TF-A_BL2_Trusted_Board_Boot#CoT)
- [ARM Trusted Firmware TBBR OID Definitions](https://github.com/ARM-software/arm-trusted-firmware/blob/master/include/tools_share/tbbr_oid.h)

## Usage

```bash
cot_signer [OPTIONS] COMMAND [ARGS]...

Options:
  -v, --verbose  Enable verbose logs
  --help         Show this message and exit

Commands:
  print-cert              Print certificate contents and verify signature
  sign-root-certs         Sign root level certificates
  sign-intermediate-certs Sign intermediate level certificates
  sign-leaf-certs         Sign leaf level certificates
  verify-cot              Verify the CoT signatures, public keys, and hashes
  verity-cot-partial      Verify the CoT signatures, public keys, and hashes without the leaf certs. This is used for verifying the partial CoT generated from a key cermeony.
```

### Common Command Examples

Each certificate level supports signing both certificates at once if all necessary arguments are provided. Since there are many arguments, it is recommended to do the signing on a per-certificate basis.

1. **Sign Root Certificates**

   a. Sign STM32MP Config Certificate:
   ```bash
   cot_signer sign-root-certs \
     --product C2 \
     --rot-key-pk ./publicKey00.pem \
     --rot-key-sk ./privateKey00.pem \
     --hw-config ./u-boot-stm32mp131f-c2evt.dtb \
     --fw-config ./stm32mp131f-c2evt-fw-config-optee.dtb \
     --stm32mp-cfg-cert ./stm32mp_cfg_cert.crt \
     --out-dir certs/
   ```

   b. Sign Trusted Key Certificate:
   ```bash
   cot_signer sign-root-certs \
     --product C2 \
     --rot-key-pk ./publicKey00.pem \
     --rot-key-sk ./privateKey00.pem \
     --trusted-world-key-pk ./trusted_world_pk.pem \
     --non-trusted-world-key-pk ./non_trusted_world_pk.pem \
     --trusted-key-cert ./trusted_key.crt \
     --out-dir certs/
   ```

2. **Sign Intermediate Certificates**

   a. Sign Trusted OS Firmware Key Certificate:
   ```bash
   cot_signer sign-intermediate-certs \
     --product C2 \
     --trusted-world-key-pk ./trusted_world_pk.pem \
     --trusted-world-key-sk ./trusted_world_sk.pem \
     --tos-fw-key-pk ./trusted_fw_content_pk.pem \
     --tos-fw-key-cert ./tos_fw_key.crt \
     --out-dir certs/
   ```

   b. Sign Non-Trusted Firmware Key Certificate:
   ```bash
   cot_signer sign-intermediate-certs \
     --product C2 \
     --non-trusted-world-key-pk ./non_trusted_world_pk.pem \
     --non-trusted-world-key-sk ./non_trusted_world_sk.pem \
     --nt-fw-key-pk ./non_trusted_fw_content_pk.pem \
     --nt-fw-key-cert ./nt_fw_key.crt \
     --out-dir certs/
   ```

3. **Sign Leaf Certificates**

   a. Sign Trusted OS Firmware Content Certificate:
   ```bash
   cot_signer sign-leaf-certs \
     --product C2 \
     --tos-fw-key-pk ./trusted_fw_content_pk.pem \
     --tos-fw-key-sk ./trusted_fw_content_sk.pem \
     --tos-fw ./tee-header_v2.bin \
     --tos-fw-extra1 ./tee-pager_v2.bin \
     --tos-fw-extra2 ./tee-pageable_v2.bin \
     --tos-fw-cert ./tos_fw_content.crt \
     --out-dir certs/
   ```

   b. Sign Non-Trusted Firmware Content Certificate:
   ```bash
   cot_signer sign-leaf-certs \
     --product C2 \
     --nt-fw-key-pk ./non_trusted_fw_content_pk.pem \
     --nt-fw-key-sk ./non_trusted_fw_content_sk.pem \
     --nt-fw ./u-boot-nodtb-stm32mp13.bin \
     --nt-fw-cert ./nt_fw_content.crt \
     --out-dir certs/
   ```

4. **Print Certificate Information**

   Print and verify a certificate:
   ```bash
   cot_signer print-cert \
     --cert ./nt_fw_content.crt \
     --security NON_TRUSTED \
     --cert-pk ./non_trusted_fw_content_pk.pem
   ```

5. **Verify Chain of Trust**

   Verify all certificates in the chain:
   ```bash
   cot_signer verify-cot \
     --product C2 \
     --rot-key-pk ./publicKey00.pem \
     --hw-config ./u-boot-stm32mp131f-c2evt.dtb \
     --fw-config ./stm32mp131f-c2evt-fw-config-optee.dtb \
     --tos-fw ./tee-header_v2.bin \
     --tos-fw-extra1 ./tee-pager_v2.bin \
     --tos-fw-extra2 ./tee-pageable_v2.bin \
     --nt-fw ./u-boot-nodtb-stm32mp13.bin \
     --certs-dir certs/
   ```

  6. **Verify Partial Chain of Trust**

   Verify the partial chain of trust:
   ```bash
   cot_signer verify-cot-partial \
     --product C2 \
     --rot-key-pk ./publicKey00.pem \
     --hw-config ./u-boot-stm32mp131f-c2evt.dtb \
     --fw-config ./stm32mp131f-c2evt-fw-config-optee.dtb \
     --tos-fw-key-pk ./c3-trusted-os-firmware-key-prod.pub.pem \
     --nt-fw-key-pk ./c3-nontrusted-os-firmware-key-prod.pub.pem \
     --certs-dir certs/
   ```

## Running Tests

Tests and test dependencies are located in the `tests` directory and use the *unittest* framework

```bash
# Run all tests
python -m unittest discover tests -v
```
