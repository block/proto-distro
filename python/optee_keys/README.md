# OP-TEE Keys Tool

A Python tool for managing the TA verification key used in OP-TEE OS / Core in order to verify signed Trusted Applications (TAs). The private part of these keys are used to sign TAs, while the public part is used by OP-TEE to verify the signature of the TA.

This modifies the verification key directly in the OPTEE ELF (`tee-stm32mp131f-c3p1.elf`) prior to it being split using `gen_tee_bin.py`.

The split files are hashed separately in the Chain of Trust (CoT) and are then packaged into the FIP (Firmware Image Package).

The split files are:

- `tee-pager_v2-stm32mp131f-c3p1.bin`
- `tee-pagable_v2-stm32mp131f-c3p1.bin`
- `tee-header_v2-stm32mp131f-c3p1.bin`

They are generated by the `gen_tee_bin.py` script, which is part of the OP-TEE build system.

```bash
./build/tmp-glibc/work/c3_p1-oe-linux-gnueabi/optee-os-stm32mp/3.16.0-stm32mp-r2.1-r0/git/scripts/gen_tee_bin.py \
	--input ./tee-stm32mp131f-c3p1.signed.elf \
	--out_pager_v2 ./tee-pager_v2-stm32mp131f-c3p1.bin \
	--out_pageable_v2 ./tee-pageable_v2-stm32mp131f-c3p1.bin \
	--out_header_v2 ./tee-header_v2-stm32mp131f-c3p1.bin
```

## Usage

```bash
# Print key information
optee-keys print-key path/to/file.elf

# Compare keys
optee-keys compare-key path/to/file.elf path/to/key.pem

# Inject key
optee-keys inject-key path/to/source.elf path/to/key.pem path/to/output.elf
```
